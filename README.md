# 每日日本語 N3–N2 練習 APP（GitHub Pages 題庫版）

這是**不需要 API、不需要付款、沒有每日雲端 AI 產題**的靜態網站版本。網站每天從內建題庫抽出 3 題，並依本機錯題紀錄稍微提高弱點題目的出現機率。

## 功能

- 顯示台灣日期與每日簽到、連續簽到天數
- 每天依日期抽出 3 題，涵蓋 N3/N2 文法、語彙、漢字讀音與用法
- 作答後顯示正解、中文翻譯、文法解說與各選項解析
- 顯示單字平假名、片假名、中文意思及音調欄位
- 錯題本、弱點統計、重做錯題、匯出錯題與學習紀錄 JSON
- 目前內建 300 題（N3/N2）；可自行編輯 `data/questions.json` 擴充

## 部署到 GitHub Pages

1. 將本專案所有檔案上傳到 GitHub repository 的**根目錄**，確保 `index.html` 與 `data/` 同層。
2. 開啟 repository 的 `Settings → Pages`。
3. 在 `Build and deployment` 選 `Deploy from a branch`。
4. 選擇 `main` 分支與 `/(root)`，儲存。
5. 等待部署完成，開啟 GitHub Pages 提供的網址。

不需要設定 API Key、Secrets、付款方式或 GitHub Actions。

## 如何擴充題庫

編輯 `data/questions.json` 的 `questions` 陣列，新增題目時沿用現有欄位格式。每題需要唯一 `id`、4 個選項、`answerIndex`（從 0 開始）、4 個選項解析、中文翻譯及 `vocabulary` 陣列。

題庫是手動維護的靜態 JSON；新增題目後 commit/push，GitHub Pages 更新後即可使用。

## 重要限制

- 每日抽題、簽到、錯題本與學習統計都在目前瀏覽器的 `localStorage`，不會跨裝置同步；清除瀏覽器資料也可能導致紀錄遺失。
- 音調欄位目前是**待核對的學習提示**，不是權威詞典驗證結果。使用時請以 NHK 日本語発音アクセント新辞典等可靠資料核對後再自行修正。
- 題庫已擴充至 300 題，但屬於學習用初稿，並非經日語教師逐題審定的正式題庫。特別是選項設計、個別句子的自然度及中文解說仍可能有疏漏，建議使用時回報或自行核對。音調資訊全部標示待核對，不應當作標準音調答案。
